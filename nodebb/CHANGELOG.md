# Changelog

## 1.0.1 - 2026-10-26

- README: a new intro that starts with the problem Privatus Analytics solves.

## 1.0.0 - 2026-10-26

- Initial release of `nodebb-plugin-privatus-analytics`.
- Adds the Privatus Analytics script to the `<head>` of every forum page through `filter:middleware.renderHeader`.
- Settings page in the admin panel for the site id, with an option to skip logged-in administrators.
- Works with NodeBB 3 and 4.
