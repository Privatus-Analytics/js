# Changelog

## 1.0.1 - 2026-10-26

## 1.0.0 - 2026-10-26

- Initial release of `directus-extension-privatus-analytics`.
- A Directus Insights panel that shows visitors, pageviews (with the change from the period before) and top pages from the Privatus Analytics API.
- Panel options for the API token, site id, period and number of top pages.
